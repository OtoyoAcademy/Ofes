# OFES Ver.1.22 - Supabase版

## Ver.1.22 追加機能

- 管理画面に「スタンプQR」タブを追加。
- スタンプ①〜⑤の固定QRコードをいつでも確認・再印刷できます。
- 「掲示用PDF（1スタンプ1ページ）」と「一覧PDF（A4 1枚）」の2種類を用意。
- QRコードは学校用URL `https://otoyoacademy.github.io/Ofes/?stamp=1` ～ `?stamp=5` に固定。翌年度以降も同じ印刷物を再利用できます。
- PDFはブラウザの印刷画面から「PDFとして保存」で作成します。

Supabaseのデータ構造・RLS・既存の公開データには変更ありません。
