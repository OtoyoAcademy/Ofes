# OFES Ver.1.31 - Supabase

GitHub Pages + Supabase で運用する OFES の本番向け版です。

## Ver.1.31 の追加内容

### 1. 複数アンケート管理
管理画面に「アンケート」を追加しました。年度ごとに必要な数だけ登録できます。

各アンケートで設定できる項目:
- アンケート名
- 案内文
- Googleフォーム等のURL
- ボタン名
- 表示 / 非表示
- 表示順
- 表示開始日時 / 表示終了日時（任意）
- 対象: 一般＋大豊学園 / 一般来場者のみ / 大豊学園のみ

来場者画面ではURLを文字列で並べず、「回答する」などのボタンとして表示します。

「大豊学園のみ」に設定したアンケートURLは一般公開payloadへ入れず、年度パスコードで入った関係者だけに表示します。

### 2. 既存の本番向け機能を継続
- Supabase公開・公開前自動復元ポイント・ワンクリック復元
- 匿名リアクションと集計PDF
- 一般来場者 / 大豊学園 / 管理画面の入口分離
- 児童生徒名の非公開領域分離
- TV表示（縦 / 横）
- スタンプラリーのアプリ内QRカメラ
- スタンプ5個達成画像
- スタンプQR PDF出力
- 年度別保存 / 前年度コピー / 削除
- 会場案内・安全情報・避難経路
- 本番前チェック
- 保護者向けお知らせPDF

## Supabaseについて
Ver.1.31では新しいテーブルやRLSは追加していません。
Ver.1.27までのSupabase追加SQLをすでに実行済みであれば、SQL Editorでの追加作業は不要です。

アンケートは既存のOFES公開JSON・大豊学園関係者用JSON・年度アーカイブJSONの中に保存します。

## 更新手順
1. 現在の設定JSONを管理画面から書き出して保存する。
2. Ver.1.31のファイルを GitHub `OtoyoAcademy / Ofes` へ上書きする。
3. GitHub Pagesを強制再読み込みする。
4. 管理画面上部が `Ver.1.31` になっていることを確認する。
5. Supabase管理者ログイン・公開データ・会場・プログラムが正常に読み込まれていることを確認する。
6. 必要に応じて「アンケート」からGoogleフォーム等を登録する。
7. 「データ保存」からSupabaseへ公開する。
8. 一般来場者 / 大豊学園の両入口で表示対象が正しいことを確認する。

## 個人情報について
児童生徒名と「大豊学園のみ」のアンケート情報は一般公開payloadへ含めません。
児童生徒名は専用欄へ入力し、発表タイトルやグループ名など一般公開欄には入力しないでください。
