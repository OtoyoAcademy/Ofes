# OFES Ver.1.52 Supabase版

- 同時刻に複数の発表がある場合、1ページあたり1〜2件を表示し8秒ごとに自動切り替えます。

- 安全情報の公開・非公開設定もそのまま維持します。

## 更新手順
1. ZIPを解凍し、その中のファイルを既存GitHub Pagesへ上書きする。
2. 更新後、ブラウザでCtrl+Shift+Rで再読込する。
3. 年度・時刻テストでイベント当日を指定し、発表が多数重なる時刻を選んでTV表示を確認する。
4. 会場案内でセッションを変更し、対象プログラムのない会場／階が表示されないことを確認する。

SupabaseのSQL変更・再公開は不要です。コードの表示変更のみです。

# OFES Ver.1.51 Supabase版

Ver.1.50を基に、**管理画面とは別のタブですでに開いているTV画面**にテスト日時が反映されない問題を修正しました。

- 同じブラウザ・同じ公開URL（オリジン）の別タブでテスト日時を変更すると、TVを再読み込みしなくても表示が更新されます。

- JavaScriptとCSSのURLのバージョン番号を両方更新し、ブラウザの旧ファイルキャッシュを回避します。

## 確認手順

1. ZIPを解凍し、中身をGitHub Pagesのリポジトリに上書きする。
2. ページを `Ctrl+Shift+R` で強制更新し、管理画面にVer.1.51が出ることを確認する。
3. 同じブラウザでOFESを2タブ開き、1タブをTV画面にする。
4. もう1タブの管理画面でテスト日時を「2026-11-21 10:05」にしてONにする。
5. TV側の表示が「2026/11/21 10:05」「テスト表示」となり、当該時間帯のプログラムが出ることを確認する。
6. テストをOFFに戻すとTV側も実日時に戻ることを確認する。

※ 画面にVer.1.51が表示されない場合は、GitHub Pagesの反映／配置／キャッシュを確認してください。
※ 別のPCやテレビ内蔵ブラウザへテスト日時を配信する機能ではありません。
※ Supabaseの追加SQL・再公開は不要です。

# OFES Ver.1.50 Supabase版

Ver.1.49を基に「テスト日時モードがTV表示に反映されない」問題を修正しました。

## 修正概要
- 管理者画面を閉じて公開データの表示に戻っても、同じブラウザのテスト日時を参照します。
- OFES TVの時計、カウントダウン、現在・次のプログラム、終了表示がテスト日時に連動します。
- テスト中のTV画面に「テスト表示」を明示します。
- テスト日時はブラウザ内だけに保存し、Supabaseの公開データには含めません。ほかの端末の来場者画面には影響しません。
- 管理画面からテスト日時をOFFにすると、TVと来場者画面は実際の日時に戻ります。

## 更新
ZIPを解凍し、フォルダ内のファイルを既存GitHub Pagesリポジトリへ上書きしてください。
更新後はブラウザの強制再読み込み（Windows: Ctrl+F5）を推奨します。
Supabaseの追加SQLは不要です。既存の登録済みデータを変更する必要もありません。

## 確認手順
1. 管理者画面の「年度・時刻テスト」でテスト日時を有効にします。
2. テスト日を開催日（例：2026-11-21）、時刻を発表時間中（例：10:05）にします。
3. 管理者画面を閉じ、TV表示を開きます。
4. TV上部に「2026/11/21 10:05」「テスト表示」が出て、当該時刻のプログラムが出ることを確認します。
5. 管理者画面に戻りテスト日時をOFFにして、TVの表示が実際の日時に戻ることを確認します。
6. 必要に応じて別の端末でTV表示を開き、その端末では実時刻のままであることを確認します。

- 参考画像は自動でJPEGに圧縮します。1画像約450KB以下、全アンケート合計約2.3MBの制限です。細かな文字が多いポスターは拡大時の見やすさを確認してください。

## 写真の保存について
写真コラージュ機能は写真保管機能ではありません。写真は作業中のブラウザ内にだけ一時保持し、ページを閉じるか「写真をリセット」すると消えます。

そのため、Supabase Storage の容量は消費しません。PDF保存前にページを閉じないでください。
