# OFES Ver.1.26 Supabase

## Ver.1.26 追加機能：アプリ内QRカメラ + 端末保存

- スタンプラリー画面の「QRコードを読み取る」から、OFES内でスマートフォンのカメラを起動します。
- QRを読み取るたびに STAMP 1〜5 の取得状況を同じアプリの localStorage に保存します。
- 外部カメラアプリへ移動しないため、ホーム画面版OFESでスタンプを続けて集めやすくなります。
- 同じQRを再度読んだ場合は「取得済み」と表示し、重複登録しません。
- 5個そろうとコンプリート表示になります。
- QR読み取りには html5-qrcode 2.3.8（Apache-2.0）をCDN経由で使用します。
- Supabaseのテーブル・RLS変更はありません。

来場者向けプログラムの「全体／1年〜9年」学年フィルターを削除し、全プログラムをそのまま時間順で確認する表示に戻しました。

## Ver.1.24 追加機能：会場案内の安全情報

管理者画面の「会場・配置図」から、来場者向けの安全情報を登録・編集できます。

### 登録できる安全情報
- 消火器
- 非常口
- AED
- 避難集合場所
- 避難経路

安全設備は図面上を1回タップして配置します。避難経路は開始地点から終了地点までドラッグします。曲がる経路は複数の線に分けて登録してください。

登録した安全情報は通常の会場・プログラムと同様にブラウザの下書きへ保存され、「データ保存」→「Supabaseへ公開」で来場者へ共有されます。JSONバックアップにも含まれます。

来場者の会場案内では安全情報を標準表示し、「安全情報を表示中」ボタンで表示・非表示を切り替えられます。

> 避難経路・設備位置は、必ず学校で正式に確認した内容を登録してください。

SupabaseのテーブルやRLSの追加変更は不要です。
