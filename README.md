# OFES Ver.1.29 - Supabase

## Ver.1.28 の主な追加機能

### 1. スタンプラリー達成画像
管理画面「スタンプQR」から、5個集めたときに表示する「おめでとう」画像をアップロードできます。
画像はブラウザ側で縮小・圧縮して下書きに保存し、「Supabaseへ公開」で来場者へ共有します。

### 2. TV表示
来場者画面に「TV表示」を追加しました。
- 横表示 / 縦表示を切替
- 全画面表示
- 開催前: 「おおフェスまであと○日」
- 開催中: 現在の発表、会場、学年・グループを表示
- 大豊学園関係者モードでは児童生徒名も表示
- プログラム終了後〜リアクション締切: リアクション受付案内
- 締切後: 「今年のおおフェスもありがとうございました。次回もお楽しみに！」

### 3. 入口を3種類に分離
最初の画面で次を選びます。
- 一般来場者
- 大豊学園（児童生徒・保護者・学校関係者）
- 管理画面

一般来場者には児童生徒名を表示しません。
「大豊学園」は年度用パスコードをSupabase側で照合し、成功したときだけ非公開の児童生徒名を取得します。

### 4. 児童生徒名の専用欄
管理画面「プログラム」に「児童生徒名（大豊学園のみ）」を追加しました。
個人名は発表内容やグループ欄ではなく、この専用欄へ入力してください。

### 5. 年度データ
管理画面「年度データ」で以下ができます。
- 現在の年度をSupabaseへ保存
- 保存した年度の内容を見る
- 前年度を新年度の下書きへコピー
- 試行中の不要な年度データを削除

年度データには会場・プログラム・安全情報・児童生徒名等を含みますが、年度用パスコードはコピーしません。

## 必須: Supabase 追加SQL
既に school-events を運用中の場合は、GitHub更新前に `supabase-upgrade-v127.sql` を Supabase SQL Editor で1回実行してください。

新規プロジェクトの場合は、更新済みの `supabase-setup.sql` を実行すればVer.1.28分も含まれます。

## 更新手順
1. 現在のVer.1.26から設定JSONを書き出す。
2. Supabase SQL Editorで `supabase-upgrade-v127.sql` を実行する。
3. Ver.1.28のファイルを GitHub `OtoyoAcademy / Ofes` へ上書きする。
4. 強制再読み込みする。
5. 管理画面 > 年度・時刻テスト で「大豊学園 関係者用パスコード」を8文字以上で設定する。
6. 各発表の児童生徒名を必要に応じて入力する。
7. 「データ保存」>「Supabaseへ公開」を実行する。
8. 一般来場者入口で児童生徒名が見えないことを確認する。
9. 大豊学園入口から年度パスコードで入り、児童生徒名が見えることを確認する。
10. TV表示、年度保存、スタンプ5個達成画像をテストする。

## 個人情報について
児童生徒名は `ofes_site_state` の一般公開payloadには含めません。
`ofes_internal_state` に分離し、パスコードは平文保存せず `pgcrypto` でハッシュ化します。
年度保存データは管理者のみ閲覧可能なRLSを設定しています。

ただし、発表タイトルやグループ欄に個人名を書いた場合は一般公開されます。個人名は必ず専用欄を使用してください。
