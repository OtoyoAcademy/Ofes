# OFES Ver.1.23 - Supabase版

## Ver.1.23 追加・調整

- 来場者向け「プログラム」に「全体／1年〜9年」の学年フィルターを追加。
- 「7年生・8年生」「7・8年生」「6〜9年生」などの合同・複数学年発表にも対応。
- 学年未指定のプログラムは全体行事として、どの学年を選んでも表示。
- 学年を選んだ状態でも、午前セッション・午後の有志発表は従来どおり折りたたみ表示。
- 来場者画面の試作・開発向け説明を整理し、本番で読みやすい文言へ変更。
- 管理者画面は操作説明を残し、学年入力と学年別表示の関係を追記。
- 公開中の通常リアクションでは、各発表下の技術的な受付説明を非表示にして画面を簡潔化。

Supabaseのテーブル・RLS・既存公開データの形式は変更していません。
