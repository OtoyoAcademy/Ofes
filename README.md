# OFES Ver.1.39 — Excel様式ダウンロードのHTTP 404修正

**修正箇所：管理者画面 → プログラム → Excel入力様式のダウンロード**

- 前版では `assets/templates/OFES_プログラム入力テンプレート_時間自動反映.xlsx` を `fetch()` で取得していました。テンプレートがGitHub Pagesの公開URLに存在しない場合、HTTP 404でダウンロードできませんでした。
- Ver.1.39では、Excelのひな形を `app.js` に内蔵しました。外部のテンプレートファイルへアクセスせず、ブラウザ内で現在登録済みの会場名・セッション時刻をExcelに反映しダウンロードします。
- 管理画面のダウンロード要素をリンクからボタンに変更し、スクリプトが動かない場合も間違ったURLを開かないようにしました。
- 既存のExcel直接読込・CSV読込、Supabaseデータ形式、管理機能は変更しません。追加SQLは不要です。

**GitHub Pages更新時は、ZIPのフォルダ内のファイルをサイトの公開フォルダへ上書きしてください。** 特に `index.html`、`app.js`、`assets/vendor/jszip.min.js` を確認してください。既存 `assets/templates` は同梱しますが、ダウンロード時には参照しません。

## 確認済み
- `node --check app.js` によるJavaScript構文検査
- ブラウザ（Chromiumの独立テスト）で、Excelのダウンロードがネットワーク取得を行わず成功することを確認
- 出力Excelの会場名、会場ID、セッション③時刻を検証
- ZIP内容とExcel内のファイル構成を検証

※ 実際のGitHub Pages・Supabase接続を伴うフル動作確認は更新後に実施してください。

# OFES Ver.1.35 - Supabase

大豊学園「おおフェス」用の GitHub Pages + Supabase 版です。

## Ver.1.35 の変更点（プログラムCSV入力支援）

- 「プログラム入力」「入力説明」「選択肢設定」の3タブをもつExcel様式（`.xlsx`）を追加しました。
- Ver.1.36以降は「種別」「セッション」「会場名」「発表学年」をプルダウンで選択します。会場は管理画面からExcelをダウンロードすると候補が自動反映されます。
- Ver.1.37では入力したExcel（.xlsx）をそのまま読み込めます。CSVへの保存は不要です。
- 従来のCSVの読み込みは継続していますが、旧CSVダウンロードボタンは誤操作防止のためVer.1.37で表示を終了しました。
- セッション時刻、会場とセッションの重複、児童生徒名の公開制御、Supabase連携など既存仕様は変更しません。
- **追加のSupabase SQLは不要です。**

## Ver.1.34 の変更点

- 入口は「一般来場者」「大豊学園関係者」の大きな2択。管理者入口は下部の小リンク。
- 入口に「撮影した写真・動画等をSNS等へ投稿しないでください」というお願いを表示。
- 大豊学園関係者パスコードは数字8〜24桁で設定・入力（スマホ数字キーボード）。**既存の英数字パスコードを使用している場合、管理者画面から数字のパスコードへ変更して再公開**してください。
- アンケートごとに参考ポスター画像（JPEG / PNG / WebP）を1枚登録。管理者画面で自動圧縮され、来場者画面で拡大可能。GoogleフォームURLは従来どおりボタンで開きます。一般公開と関係者専用の区別を維持します。画像データはSupabaseに公開操作したときに保存されます。写真コラージュの写真とは扱いが異なります。
- スタンプラリーQRコード印刷：B案カラーカード型。1=赤、2=青、3=緑、4=オレンジ、5=紫。番号を大きく印刷し、**場所名は印刷しません**。A4の1枚1コード掲示用と5コード一覧用。
- 画像認識によるプログラム自動登録は追加しません。ChatGPTで文書から既存のCSV様式に変換し、現在のCSV取込機能を利用します。
- 既存の写真コラージュ、Supabase、CSV、リアクション、地図等の機能は維持。

### アップデート手順

1. Ver.1.33の設定JSONを管理画面からバックアップします。
2. ZIP内のファイル・フォルダの**中身**を、既存のGitHub Pagesレポジトリに上書きします。Supabase追加SQLは不要です。
3. ブラウザを強制再読み込み（PCでは Ctrl+Shift+R）し、管理画面の Ver.1.34 表示を確認します。
4. 管理者画面「年度・時刻テスト」で、関係者用パスコードを数字8〜24桁に設定して保存し「データ保存」→「Supabaseへ公開」。既に使用している番号も、確認して保存・公開してください。
5. アンケート画像の表示・拡大、Googleフォームへの遷移、QRコード印刷を実機確認してください。

### アンケート画像の運用上の注意

- 参考画像は自動でJPEGに圧縮します。1画像約450KB以下、全アンケート合計約2.3MBの制限です。細かな文字が多いポスターは拡大時の見やすさを確認してください。
- 添付画像は公開データ（または関係者専用データ）のJSONへ格納されます。児童生徒の顔や個人情報など、公開すべきでない写真・資料を添付しないでください。
- 管理画面で登録した直後は下書きです。「Supabaseへ公開」するまでは他端末に反映されません。
- 長期的に多数の高解像度ポスターを掲載する場合は、将来Supabase Storage等への移行を検討してください。

## Ver.1.33 の追加内容

### A4横 写真コラージュ
管理画面に **「📷 写真コラージュ」** を追加しました。

- 作成するプログラムを選択すると、用紙タイトルを自動入力します。
- タイトルはPDF用に自由に変更できます。元のプログラム名は変更しません。
- 「午後の有志発表（まとめ）」を選び、午後の発表を1枚にまとめられます。
- 写真は **3〜40枚程度** を想定しています（1枚からでも作成できます）。
- 「SDカード・フォルダから選ぶ」「写真をまとめて追加」「ドラッグ＆ドロップ」の3通りで追加できます。
- 読み込んだ写真はブラウザ内で印刷用・サムネイル用に縮小し、**Supabase / GitHub にはアップロードしません**。
- メイン写真を最大3枚まで指定できます。
- レイアウトは以下から選択できます。
  - 自動おすすめ
  - 左に大写真
  - 右に大写真
  - 上に大写真
  - 雑誌風
  - ランダムモザイク
  - スクラップブック（傾きあり）
  - 高密度
- 「別のレイアウトにする」で写真順・配置を変えられます。
- A4横・高解像度の印刷画面を開き、ブラウザから「PDFとして保存」できます。
- PDF画面を開いた後、次の用紙作成用に写真をリセットできます。

### リアクション連携
写真コラージュで選択した発表のリアクションをSupabaseから集計し、用紙下部に
`👍 / 💡 / ✨ / 😊 / 🙌` の件数を表示できます。

「午後の有志発表（まとめ）」では、対象となる午後の発表のリアクションを合計します。
リアクション表示はON/OFFでき、最も多かったリアクションの表示も選択できます。

※ 集計の取得には Supabase の管理者ログインが必要です。

### デモデータ
「デモデータを登録」で追加するデモ発表に、**架空の児童生徒名**も入るようにしました。
これにより、一般来場者では名前が表示されず、「大豊学園関係者」入口では名前が表示されることを確認できます。

## 写真の保存について
写真コラージュ機能は写真保管機能ではありません。写真は作業中のブラウザ内にだけ一時保持し、ページを閉じるか「写真をリセット」すると消えます。

そのため、Supabase Storage の容量は消費しません。PDF保存前にページを閉じないでください。
